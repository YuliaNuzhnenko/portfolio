Spatial Transcriptomics Microenvironment Atlas

10x Visium & Xenium In Situ Spatial Neighborhood Mapping
Spatial Transcriptomics Squidpy Seurat v5 10x Visium
Scientific Overview

Preserves spatial cellular architecture in tissue sections without dissociation. Computes Delaunay spatial contact graphs, Moran's I spatial autocorrelation for spatially variable genes (SVGs), and maps cell-cell ligand-receptor communication networks within tumor microenvironments.

Repository: github.com/YuliaNuzhnenko/spatial-transcriptomics-atlas
Platforms Supported: 10x Visium, Xenium In Situ, MERFISH, Stereo-seq
Core Statistics: Moran's I Spatial Autocorrelation, Cell-Cell Proximity Networks
Open GitHub Repository

AlphaFold3 Biomolecular Complex & Interaction Evaluator

Multi-Chain Complex Interface & PAE Matrix Scoring
AlphaFold3 DiffDock PAE Analysis Biopython
Scientific Overview

Extends 3D protein structure prediction to multi-chain complex systems (Protein-DNA, Protein-RNA, Protein-Ligand). Parses 2D Predicted Aligned Error (PAE) matrices to decouple inter-chain domain confidence from intra-chain errors and computes solvent-accessible surface area (SASA) burial.

Repository: github.com/YuliaNuzhnenko/alphafold3-complex-docking
Complex Types: Protein-Protein, Protein-DNA, Protein-RNA, Protein-Small Molecule
Metrics: Inter-Chain PAE (Å), Delta SASA (Å²), Active Site Mutation Hotspots
Open GitHub Repository

Single-Cell RNA Velocity & Trajectory Inference Engine

scVelo Splicing Kinetics & CellRank Fate Drivers
RNA Velocity scVelo CellRank AnnData
Scientific Overview

Calculates time-resolved single-cell transcriptomic velocity vectors from ratios of unspliced pre-mRNA to spliced mature mRNA. Fits kinetic differential equations and applies CellRank absorbing Markov chains to predict cell fate decisions in stem cell differentiation and tumor evolution.

Repository: github.com/YuliaNuzhnenko/sc-rna-velocity-trajectory
Kinetics Model: Splicing Differential Equations (du/dt = α - βu, ds/dt = βu - γs)
Outputs: Velocity Stream UMAP, Absorbing Fate Probabilities, Velocity Pseudotime
Open GitHub Repository
